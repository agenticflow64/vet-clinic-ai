# Сценарий демо (≤ 2 минут)

Цель ролика: показать, что AI-ассистент выглядит и работает как часть сайта
ветеринарной клиники kashtanka64.ru, при этом честно оставаясь демо-стендом.

Подготовка (до записи):

```bash
cd vet-clinic-ai
set -a; source .env; set +a
.venv/bin/python scripts/ingest.py
.venv/bin/uvicorn app.main:app --port 8010
```

Открыты две вкладки: **kashtanka64.ru** (живой сайт) и
**localhost:8010/demo** (демо-страница с виджетом).

---

## Хронометраж

**0:00–0:15 — живой сайт.**
Краткий обзор kashtanka64.ru: шапка, раздел «Цены», телефон. Одна фраза:
«Это реальный сайт клиники, мой fullstack-проект. Теперь покажу AI-ассистент,
который я подготовил для встраивания в него».

**0:15–0:30 — демо-страница.**
Переключаемся на `localhost:8010/demo`. Обратить внимание: шапка в стиле
сайта, светлая тема, скромная лента «демо-стенд» поверх шапки.

**0:30–0:55 — вопрос по прайсу.**
В чате: «Сколько стоит стерилизация кошки?»
Ответ: точная услуга и цена из прайса (Стерилизация кошки — 5000 руб.).
Ещё один: «А УЗИ сердца собаке?» (УЗИ сердца ЭхоКГ — 3000 руб.).
Фраза: «Отвечает по реальному прайсу клиники, ничего не выдумывает».

**0:55–1:20 — триаж.**
«Кот уже сутки не может пописать, кричит».
Ответ: срочность «срочно к врачу» (бейдж в чате), уточняющий вопрос,
дисклеймер «не заменяет консультацию ветеринара».
Фраза: «Для неострых случаев будет планово — и всегда с оговоркой про врача».

**1:20–1:50 — запись на приём.**
«Хочу записать собаку на приём» → ассистент спрашивает вид животного и время
→ «Лабрадор Барон, на субботу к 12 дня» → спрашивает телефон →
«+7 927 100-20-30» → подтверждение с номером заявки.

**1:50–2:00 — админка.**
Открываем `localhost:8010/admin`: заявка от чата на месте; меняем статус
«новая» → «подтверждена».

---

Финальная фраза: «Стенд отдельным сервисом, встраивается в сайт одной строкой
iframe или скрипта — инструкция в docs/integration.md».

## Что подчёркивать (честность)

- Сайт клиники — реальный прод (kashtanka64.ru), ассистент — демо-стенд,
  готовый к встраиванию, заказчику не внедрялся.
- Цены в ответах — из настоящего прайса клиники.
- Триаж не заменяет ветеринара — дисклеймер в каждом ответе.
